# Refonte Graphique — Maquettes Sentinel

Ce répertoire regroupe les travaux préparatoires et les maquettes interactives ayant servi à la refonte de l'interface Sentinel pour l'application Sovereign OS DIM.

## Contenu

- `project/` : Prototypes d'écrans au format HTML/CSS/JS.
- `chats/` : Transcriptions des spécifications de design discutées lors de la conception des interfaces.
